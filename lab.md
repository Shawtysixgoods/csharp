# Техническое задание — Система управления авиакомпанией

**Версия:** 1.0
**Платформа:** .NET / C#
**Тип проекта:** Console Application

---

## 1. Общее описание системы

Настоящее техническое задание описывает архитектуру программного модуля, реализующего модель авиакомпании. Система включает управление парком воздушных судов (пассажирских и грузовых) и расписанием рейсов. Структурная схема объектной модели:

```
Airline
├── List<AircraftBase>
│   ├── PassengerAircraft
│   │   └── List<SeatInfo>
│   └── CargoAircraft
└── List<Flight>
        └── AircraftBase (ссылка на экземпляр из парка)
```

---

## 2. Спецификация компонентов

### 2.1. Перечисление `FlightStatus`

**Тип:** `enum`

**Назначение:** типобезопасное представление допустимых состояний рейса. Исключает использование произвольных строковых значений в поле статуса.

**Допустимые значения:**

| Значение | Описание |
|---|---|
| `Scheduled` | Рейс запланирован |
| `Boarding` | Идёт посадка |
| `Departed` | Рейс вылетел |
| `Delayed` | Рейс задержан |
| `Cancelled` | Рейс отменён |
| `Landed` | Рейс приземлился |

**Область применения:** поле `Status` в классе `Flight`.

---

### 2.2. Структура `SeatInfo`

**Тип:** `struct`

**Назначение:** хранение атрибутов одного пассажирского места воздушного судна. Структура применяется в качестве примитивного объекта-значения (Value Object) без поведения, что соответствует семантике типа `struct` в C# — размещению в стеке и передаче по значению.

**Поля:**

| Поле | Тип | Описание |
|---|---|---|
| `SeatNumber` | `string` | Номер места, например `12A` |
| `Class` | `string` | Класс: `Economy`, `Business`, `First` |
| `IsOccupied` | `bool` | Признак занятости места |

**Область применения:** коллекция `List<SeatInfo>` внутри `PassengerAircraft`. Отношение является **композицией** — экземпляры `SeatInfo` не существуют вне контекста воздушного судна.

---

### 2.3. Интерфейс `ISchedulable`

**Тип:** `interface`

**Назначение:** определяет контракт для объектов, участвующих в расписании. Обеспечивает полиморфную обработку расписаний различной природы (рейсы, техническое обслуживание и т.д.) без изменения кода потребителей.

**Требуемые члены:**

| Член | Возвращаемый тип | Описание |
|---|---|---|
| `GetDepartureDate()` | `DateTime` | Дата и время вылета |
| `GetArrivalDate()` | `DateTime` | Дата и время прилёта |
| `IsUpcoming()` | `bool` | Признак того, что событие ещё не произошло |

**Реализуется:** классом `Flight`.

---

### 2.4. Абстрактный класс `AircraftBase`

**Тип:** `abstract class`

**Назначение:** базовая сущность для всех типов воздушных судов. Непосредственное инстанцирование запрещено. Содержит реализацию общей для всех наследников логики и объявляет абстрактные члены, обязательные к переопределению.

**Поля:**

| Поле | Тип | Описание |
|---|---|---|
| `TailNumber` | `string` | Бортовой номер |
| `Model` | `string` | Модель воздушного судна |
| `ManufactureYear` | `int` | Год выпуска |
| `MaxRangeKm` | `double` | Максимальная дальность полёта, км |

**Абстрактный метод:**

```csharp
public abstract string GetAircraftType();
```

Каждый наследник обязан вернуть строковое обозначение своего типа.

**Конкретный метод:**

```csharp
public int GetAge()
```

Вычисляет возраст воздушного судна на основе текущего года и `ManufactureYear`. Реализован на уровне базового класса, так как алгоритм идентичен для всех типов.

**Область применения:** поле `Aircraft` в классе `Flight` объявлено с типом `AircraftBase`, что обеспечивает независимость рейса от конкретного типа воздушного судна.

---

### 2.5. Класс `PassengerAircraft`

**Тип:** `class` (наследует `AircraftBase`)

**Назначение:** представляет пассажирское воздушное судно.

**Дополнительные поля:**

| Поле | Тип | Описание |
|---|---|---|
| `Seats` | `List<SeatInfo>` | Перечень мест на борту |

**Методы:**

| Метод | Возвращаемый тип | Описание |
|---|---|---|
| `GetAvailableSeatsCount()` | `int` | Количество свободных мест (LINQ: `Count`) |
| `GetOccupiedSeatsCount()` | `int` | Количество занятых мест (LINQ: `Count`) |
| `GetAircraftType()` | `string` | Возвращает `"Passenger"` |

---

### 2.6. Класс `CargoAircraft`

**Тип:** `class` (наследует `AircraftBase`)

**Назначение:** представляет грузовое воздушное судно.

**Дополнительные поля:**

| Поле | Тип | Описание |
|---|---|---|
| `MaxPayloadTons` | `double` | Максимальная грузоподъёмность, тонн |
| `CurrentLoadTons` | `double` | Текущая загрузка, тонн |
| `CargoType` | `string` | Тип груза |

**Методы:**

| Метод | Возвращаемый тип | Описание |
|---|---|---|
| `IsOverloaded()` | `bool` | `true`, если `CurrentLoadTons > MaxPayloadTons` |
| `GetLoadPercentage()` | `double` | Процент загруженности относительно максимума |
| `GetAircraftType()` | `string` | Возвращает `"Cargo"` |

---

### 2.7. Класс `Flight`

**Тип:** `class`, реализует `ISchedulable`

**Назначение:** сущность, описывающая один рейс в расписании авиакомпании. Является основным объектом для LINQ-запросов.

**Поля:**

| Поле | Тип | Описание |
|---|---|---|
| `FlightNumber` | `string` | Номер рейса, например `SU-101` |
| `OriginCity` | `string` | Город вылета |
| `DestinationCity` | `string` | Город прилёта |
| `DepartureTime` | `DateTime` | Дата и время вылета |
| `ArrivalTime` | `DateTime` | Дата и время прилёта |
| `Status` | `FlightStatus` | Текущий статус рейса |
| `Aircraft` | `AircraftBase` | Ссылка на назначенное воздушное судно |

> **Архитектурное примечание.** Поле `Aircraft` хранит **ссылку** на экземпляр из парка воздушных судов, а не встроенную копию объекта. Одно воздушное судно может быть назначено на несколько рейсов. Отношение между `Flight` и `AircraftBase` является **агрегацией**, а не композицией.

**Методы:**

| Метод | Возвращаемый тип | Описание |
|---|---|---|
| `GetDuration()` | `TimeSpan` | Длительность рейса (`ArrivalTime - DepartureTime`) |
| `ChangeStatus(FlightStatus)` | `void` | Устанавливает новый статус рейса |
| `GetDepartureDate()` | `DateTime` | Реализация `ISchedulable` |
| `GetArrivalDate()` | `DateTime` | Реализация `ISchedulable` |
| `IsUpcoming()` | `bool` | Реализация `ISchedulable` |

---

### 2.8. Класс `Airline`

**Тип:** `class`

**Назначение:** корневой агрегат системы. Владеет всеми коллекциями и предоставляет методы управления данными и аналитические LINQ-запросы.

**Поля:**

| Поле | Тип | Описание |
|---|---|---|
| `Name` | `string` | Наименование авиакомпании |
| `IATACode` | `string` | Код ИАТА, например `SU` |
| `Flights` | `List<Flight>` | Список рейсов |
| `Aircraft` | `List<AircraftBase>` | Парк воздушных судов |

**Методы управления:**

| Метод | Описание |
|---|---|
| `AddFlight(Flight)` | Добавляет рейс в расписание |
| `AddAircraft(AircraftBase)` | Добавляет воздушное судно в парк |
| `RemoveFlight(string flightNumber)` | Удаляет рейс по номеру |

**LINQ-методы:** описаны в разделе 3.

## 3. Требования к тестовым данным и аналитическим запросам

### 3.1. Минимальный объём тестовых данных

При инициализации объект `Airline` должен содержать:
- не менее **5 воздушных судов** (комбинация `PassengerAircraft` и `CargoAircraft`);
- не менее **8 рейсов** с различными статусами, маршрутами и датами.

### 3.2. Перечень обязательных LINQ-запросов

Все запросы реализуются как методы класса `Airline` и выводят результаты в стандартный поток вывода.

| № | Метод | Используемые операторы | Описание |
|---|---|---|---|
| 1 | `GetDelayedOrCancelledFlights()` | `Where` | Рейсы со статусом `Delayed` или `Cancelled` |
| 2 | `GetFlightsSortedByDeparture()` | `OrderBy` | Рейсы, упорядоченные по дате вылета |
| 3 | `FindFlightByNumber(string)` | `FirstOrDefault` | Поиск рейса по номеру |
| 4 | `GetFlightsFromCity(string)` | `Where` | Рейсы из указанного города вылета |
| 5 | `GetTop3LongestFlights()` | `OrderByDescending`, `Take` | Три рейса с наибольшей длительностью |
| 6 | `GetFlightCountByStatus()` | `GroupBy` | Количество рейсов по каждому статусу |
| 7 | `GetPassengerAircraftOlderThan10Years()` | `OfType<T>`, `Where` | Пассажирские суда старше 10 лет |
| 8 | `GetAverageFleetRange()` | `Average` | Средняя дальность полёта по парку |
| 9 | `HasFlightDepartingToday()` | `Any` | Наличие рейсов с вылетом в текущую дату |
| 10 | `GetDistinctDestinationCities()` | `Select`, `Distinct` | Уникальные города назначения |
