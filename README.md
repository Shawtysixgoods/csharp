# OOP Hotel Booking System

## Описание проекта
Данный проект представляет собой консольное приложение на языке C# для управления бронированием номеров в отеле.
Программа демонстрирует профессиональное применение принципов объектно-ориентированного программирования (ООП):
- **Инкапсуляция**: Скрытие внутренней реализации классов и защита данных (например, управление доступностью номеров).
- **Наследование**: Использование базового абстрактного класса `Room` и производных классов `StandardRoom` и `SuiteRoom`.
- **Полиморфизм**: Переопределение виртуальных методов (например, `GetDetails`) для вывода информации, специфичной для каждого типа номера.
- **Абстракция**: Использование интерфейсов (`IRoom`) и абстрактных классов.

Приложение позволяет:
- Просматривать список доступных номеров разных категорий.
- Оформлять бронирование номеров на заданное количество ночей.
- Автоматически рассчитывать итоговую стоимость проживания.
- Предотвращать двойное бронирование одного и того же номера.

## Состав команды и распределение ролей

- **Иванов Иван**
  - Проектирование архитектуры классов и интерфейсов (`IRoom`, `Room`).
  - Реализация базовой логики проверки доступности номеров.

- **Петров Петр**
  - Разработка производных классов номеров (`StandardRoom`, `SuiteRoom`).
  - Разработка класса пользователя (`Customer`) и системы резерваций (`Reservation`).

- **Сидоров Сидор**
  - Создание управляющего класса (`HotelManager`).
  - Интеграция компонентов в точку входа приложения (`Program.Main`).
  - Написание данного отчета (README.md).
