# Практическое задание
Тематика: **Система управления библиотекой — C#**

---

## Цель работы
Данная работа представляет из себя уже готовый проект на C#.
Проект запускается, но работает некорректно: в коде содержатся логические,  
вычислительные и структурные ошибки. Ваша задача — найти их самостоятельно,  
исправить, улучшить код и покрыть его тестами.

---

```text
LibrarySystem/
├── Program.cs
```

### Задание 2 — Обработка исключений

После того как вы исправили все ошибки, добавьте в каждый метод **обработку исключительных ситуаций**.  
Используйте конструкцию `try / catch / finally` там, где это уместно.  
Где нужна проверка входных данных — используйте `throw` в начале метода.

**Все ситуации ниже обязательно должны быть обработаны:**

| Ситуация | Исключение | Где возникает |
|---|---|---|
| Файл не найден | `FileNotFoundException` | `FileService` |
| Некорректный формат данных в файле | `FormatException` | `FileService` |
| Книга не найдена по ISBN | `InvalidOperationException` | `BookService`, `LoanService` |
| Читатель не найден по ID | `InvalidOperationException` | `ReaderService`, `LoanService` |
| Книга уже выдана / нет свободных копий | `InvalidOperationException` | `LoanService` |
| Читатель превысил лимит книг | `InvalidOperationException` | `LoanService` |
| Передан `null` или пустая строка | `ArgumentNullException` | Все сервисы |
| Некорректное числовое значение | `ArgumentOutOfRangeException` | `Book`, `Loan` |
| Ошибка записи в файл | `IOException` | `FileService` |
| Займ не найден по ID | `InvalidOperationException` | `LoanService` |
И другие.

**Тест-кейсы** *(минимальный список)*:
