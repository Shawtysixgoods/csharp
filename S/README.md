## Справочный материал

Перед выполнением заданий ознакомьтесь с теорией.

### Алгоритмы хеширования

| Алгоритм | Длина хеша | Назначение | Рекомендуется |
|---|---|---|---|
| `MD5` | 128 бит / 32 символа | Проверка целостности файлов |  Устарел |
| `SHA-1` | 160 бит / 40 символов | Проверка целостности |  Устарел |
| `SHA-256` | 256 бит / 64 символа | Хеширование паролей, подписи | Уверенно |
| `SHA-512` | 512 бит / 128 символов | Повышенная безопасность | Уверенно |
| `HMAC-SHA256` | 256 бит / 64 символа | Верификация с секретным ключом | Уверенно |

### Соль (Salt)

**Соль** — случайная строка, добавляемая к паролю перед хешированием.  
Защищает от атак по словарю и радужных таблиц.

```
hash = SHA256(password + salt)
```

### Как работает HMAC

**HMAC** (Hash-based Message Authentication Code) — алгоритм верификации,  
использующий секретный ключ вместе с хеш-функцией.

```
HMAC = H(key XOR opad || H(key XOR ipad || message))
```

### Проверка целостности файла

Для проверки того, что файл не был изменён, сравниваются хеши:
```
originalHash == ComputeHash(currentFileContent)
```

### Кодирование результата

Байтовый массив хеша преобразуется в строку:
- **HEX** — `BitConverter.ToString(bytes).Replace("-", "").ToLower()`
- **Base64** — `Convert.ToBase64String(bytes)`
