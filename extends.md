## Цель задания
Изучить классы, наследование, вызов `base()` в конструкторах, свойства с инициализаторами 
и переопределение `virtual` методов. Реализовать систему умного дома с базовым классом `SmartDevice` и производным `SmartLight`.

## Базовый класс SmartDevice
Создайте класс `SmartDevice` со следующими характеристиками:

**Конструктор принимает:**
- Название устройства
- Потребляемую мощность (Вт)

**Свойства с инициализаторами:**
- Название устройства
- Мощность потребления
- Состояние включения/выключения

**Виртуальные методы:**
- Включение устройства
- Выключение устройства
- Получение текущего статуса
- Строковое представление объекта

**Метод обработки команд:**
- Выполняет команды только при включенном состоянии, иначе выбрасывает исключение

## Производный класс SmartLight
Создайте класс `SmartLight`, наследующийся от `SmartDevice`:

**Конструктор:**
- Принимает название, мощность, начальную яркость
- Вызывает `base()` для базовых параметров
- Выводит сообщение о создании светильника

**Дополнительные свойства:**
- Яркость (0-100%)

**Переопределенные методы:**
- Включение: вызывает `base()` + устанавливает максимальную яркость + сообщение
- Выключение: **ВАЖНО** вызывает `base()` правильно (исправить ошибку из примера)
- Статус: показывает мощность, яркость, состояние
- Строковое представление: включает яркость

## Требования к реализации
**Обязательно использовать:**
- Инициализаторы свойств в базовом классе
- `base()` во всех конструкторах и переопределяемых методах
- `virtual` в базовом классе, `override` в производном
- Проверку состояния перед выполнением команд
- Валидацию: яркость 0-100, мощность > 0

**Обработка исключений:**
- Устройство выключено
- Некорректные параметры

## Основная программа
Создайте демонстрацию работы:

1. Создать светильник для гостиной
2. Вывести строковое представление
3. Включить устройство
4. Отправить команду изменения цвета
5. Показать статус
6. Выключить устройство

**Ожидаемый вывод:**
```
Создан светильник: Гостиная [75%], 60Вт
Свет: Гостиная [100%]
Устройство Гостиная включено
Гостиная: Вкл, 60Вт, 100%
Гостиная выключен
```

## Ключевые концепции
**`base()`** вызывает конструктор/методы родителя, **инициализаторы свойств** упрощают создание, 
**`virtual/override`** обеспечивает полиморфизм. 
**SmartLight IS-A SmartDevice** — правильное отношение наследования с обязательным вызовом базовых методов.
