**Задание: Система рисования фигур**

Создайте программу для простой системы рисования геометрических фигур. Программа должна уметь создавать круги и прямоугольники, рисовать их на "холсте" (консоль) и вычислять их площадь.

**Требования:**

1. Создайте базовый класс `Figure` с:
   - виртуальным методом `Draw()` — выводит ASCII-арт фигуры в консоль
   - виртуальным методом `GetArea()` — возвращает площадь фигуры как `double`

2. Создайте два класса-наследника:
   - `Circle` — круг с радиусом (площадь = π * r², используйте `Math.PI`)
   - `Rectangle` — прямоугольник с шириной и высотой (площадь = width * height)

3. Создайте класс `FigureManager` с методом `CreateFigure(string type, params double[] parameters)`, который:
   - При `type = "circle"` создаёт `Circle` с радиусом из первого параметра
   - При `type = "rectangle"` создаёт `Rectangle` с шириной и высотой из параметров
   - Возвращает готовую фигуру типа `Figure`

4. В `Main()` протестируйте:
   ```
   FigureManager manager = new FigureManager();
   
   Figure circle = manager.CreateFigure("circle", 3.0);
   circle.Draw();
   Console.WriteLine($"Площадь: {circle.GetArea():F2}");
   
   Figure rect = manager.CreateFigure("rectangle", 4.0, 2.5);
   rect.Draw();
   Console.WriteLine($"Площадь: {rect.GetArea():F2}");
   ```

**Пример вывода для круга (радиус 3):**
```
   *****
 *       *
*         *
 *       *
   *****
Площадь: 28.27
```
